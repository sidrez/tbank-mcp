# T-Bank MCP — только чтение

Read-only версия [исходного T-Bank MCP](https://github.com/icyberdeveloper/tbank-mcp).
Неофициальный клиент мобильного API Т-Банка. Изменяющие действия не доступны через MCP.

**[Пошаговое подключение к ChatGPT на русском →](docs/CHATGPT_RU.md)**

## Что доступно

| Инструмент | Данные |
| --- | --- |
| `session_status` | Проверка банковской сессии |
| `list_accounts` | Счета и балансы |
| `list_operations` | История операций |
| `spending_categories` | Расходы по категориям |
| `operations_histogram` | График расходов |
| `get_data` | 20 разрешённых разделов: кредиты, выписки, подписки, счета к оплате, финансовые показатели |
| `list_cards` | Список карт, маскированные номера |
| `card_limits` | Текущие лимиты карты |
| `card_operations` | История операций по карте |
| `account_requisites` | Реквизиты банковского счёта |
| `bank_documents` | Список уже заказанных справок |
| `insurance_policies` | Действующие страховые полисы |
| `invest_accounts` | Инвестиционные счета |
| `invest_portfolio` | Статистика портфеля |
| `invest_operations` | Брокерские операции |
| `invest_securities` | Бумаги в портфеле |
| `flows` | Справка по разрешённым вызовам |

Всего 17 инструментов. Переводы, оплаты, подтверждение платежей, покупки,
бронирования, отмены, сообщения, полный номер карты/CVV и паспортные документы
не публикуются. Вход через инструменты модели также отключён.

## Установка из этого репозитория

Python 3.11 или новее. PowerShell / Windows:

```powershell
git clone --branch readonly-chatgpt https://github.com/sidrez/tbank-mcp.git
cd tbank-mcp
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\tbank-mcp-login.exe +7XXXXXXXXXX
```

Linux / macOS:

```bash
git clone --branch readonly-chatgpt https://github.com/sidrez/tbank-mcp.git
cd tbank-mcp
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/tbank-mcp-login +7XXXXXXXXXX
```

В скачанном архиве начинайте с `cd` в распакованную папку.
Команда `pip install tbank-mcp` без пути устанавливает пакет из PyPI:
он принадлежит исходному проекту и может содержать инструменты записи.
Для этой версии устанавливайте именно данный исходный код.
Chromium и браузер Playwright устанавливать не требуется.

## Подключение

Локальные MCP-клиенты запускают `.venv/Scripts/tbank-mcp.exe` (Windows)
или `.venv/bin/tbank-mcp` (Linux/macOS). Это stdio-сервер.
JSON с `command` нельзя импортировать в ChatGPT web как удалённый сервер.
Для ChatGPT используйте [приватный Secure MCP Tunnel](docs/CHATGPT_RU.md).
Эта версия не открывает HTTP-порт и не реализует собственный OAuth-сервис.

## Как обеспечивается read-only

1. `readonly.READONLY_TOOLS` — явный список: новые инструменты автоматически не публикуются.
2. Все опубликованные инструменты имеют `readOnlyHint=true`, `destructiveHint=false`.
3. Сервер загружает сессию только через `ReadOnlyMobileSession`; её HTTP-транспорт
   проверяет конечные метод, HTTPS-хост и путь по независимому списку, включая редиректы.
4. `get_data` принимает только 20 явно разрешённых разделов. Произвольные API-запросы отсутствуют.
5. Из POST разрешены только ping сессии и обмен **refresh_token** на токен.
   Авторизация по SMS/паролю и silent login недоступны MCP; повторный вход выполняется в терминале.

Read-only относится к банковским бизнес-действиям. Обновление токена,
продление сессии, сохранение сессии и построение локального CA bundle остаются.
Исходный Python-клиент и локальные функции сохранены для CLI входа и регрессионных
тестов; это не интерфейс для недоверенного исполнения Python-кода.
Банковская сессия сама по себе не является выданным банком read-only токеном:
граница чтения реализована в MCP. Храните файл сессии как секрет.

Один процесс обслуживает одну банковскую сессию. Все пользователи с доступом к
этому экземпляру видят данные одного владельца. Для разных владельцев нужны
разные файлы `TBANK_SESSION`, процессы и туннели.

## Проверка

```powershell
$env:PYTHONUTF8 = '1'
.\.venv\Scripts\python.exe tests/test_readonly.py
.\.venv\Scripts\python.exe tests/test_docs_match_code.py
```

Первый тест проверяет политики HTTP, запрет платежей и реальное stdio MCP discovery.
Сетевые обращения к банку заменены тестовым адаптером. Общий унаследованный
набор запускается через `python tests/run_all.py`; тесты изолированы по процессам.

Пароль, PIN и SMS-код вводите только в локальном CLI. Для отключения локальной
трассировки задайте `TBANK_TRACE=0` перед запуском. Данные, прочитанные через
MCP, попадают в контекст ChatGPT; подключайте только нужные аккаунты.
